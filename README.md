# Esonet AI Hub

Build the complete Esonet Concept AI Skill Training website and web app.

Brand & Contact:
- Business Name: Esonet Concept AI Skill Training
- Email: info@esonetconcept.com
- WhatsApp: +234 704 820 0526
- Facebook / Instagram: esonet concept
- Logo: Incorporate the attached globe logo into navigation, hero/brand elements, and footer.

Main Pages & Sections:
1. Home: Modern AI-tech hero ("Master AI Skills. Build Your Future"), value proposition, clear CTAs ("View Courses", "Enroll Now", and "Chat on WhatsApp" linked to wa.me/2347048200526), featured courses, "Why Choose Esonet Concept", step-by-step training process, CTA banner, and comprehensive footer.
2. About Us: Mission, vision, practical approach to AI skill building for beginners, professionals, entrepreneurs, and students.
3. AI Training Courses & Course Details: Dynamic catalog (e.g. AI for Beginners, ChatGPT & Generative AI, AI for Business, AI Content Creation, AI Productivity Tools, Prompt Engineering) showing pricing in NGN (₦), duration, skill level, curriculum modules, and enrollment buttons.
4. Registration / Enrollment: Student registration collecting Full Name, Email, Phone/WhatsApp number, Selected Course, Country, and Password.
5. Payment System (Paystack readiness): Prepared for Paystack in Nigerian Naira (NGN). Because keys are not yet provided, show a clear "Payment configuration required" state rather than simulated payments. Include an Admin Settings panel to configure Paystack Public Key, Paystack Secret Key (stored securely on the backend), and Test/Live mode toggle.
6. Student Dashboard: Welcome view, student profile, enrolled courses, payment status, course materials/modules, and training progress.
7. Admin Dashboard:
   - Overview metrics: total students, courses, enrollments, revenue, pending and successful payments.
   - Course Management: Add, edit, delete, publish/unpublish, set NGN pricing, add syllabus/modules, and upload images.
   - Student & Enrollment Management: View and search students, review enrollments, toggle account status.
   - Payment Management: Transaction log with search/filter by status (Pending, Successful, Failed, Refunded), transaction references, and revenue totals.
   - Website Settings: Update business info, contact details, social links, and Paystack API credentials.
8. Contact Page: Contact form, direct email and WhatsApp links, and interactive WhatsApp chat button.
9. Backend & File Storage: Set up data models for courses, modules, enrollments, payments, settings, and contact messages, with file storage enabled for course cover images and uploads. Clean, modern, responsive design across mobile, tablet, and desktop.
